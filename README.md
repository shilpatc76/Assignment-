# Retail Sales Data Processing and Business Insights Generation

## Project Overview
This project implements an end-to-end data engineering pipeline for retail sales data. The solution performs data ingestion, cleaning, transformation, PII masking, KPI generation, and Power BI visualization.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- Power BI
- Excel

## Dataset
- product_details
- retail_data1
- retail_data2

## Data Engineering Activities
- Data Ingestion
- Duplicate Removal
- Missing Value Handling
- Product Standardization
- PII Masking
- Revenue Calculation
- KPI Generation

## Power BI Dashboard Pages
1. Executive Summary
2. Revenue Analysis
3. Product Performance
4. Category Trends
5. Regional Insights
6. Data Quality Dashboard

## KPIs
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Revenue by Category
- Revenue by City
- Top Category
- Best Selling Product
